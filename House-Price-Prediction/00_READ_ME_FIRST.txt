TROUBLESHOOTING QUICK REFERENCE
════════════════════════════════════════════════════════════════════════════════

Issue: "Python command not found"
Fix: Install Python from https://www.python.org/downloads/
     Check "Add Python to PATH"

Issue: "ModuleNotFoundError"
Fix: Activate venv: venv\Scripts\activate
     Install deps: pip install -r requirements.txt

Issue: "dataset.csv not found"
Fix: Check you're in correct directory:
     cd "...House-Price-Prediction"

Issue: "house_price_model.pkl not found"
Fix: Train the model: python model.py

Issue: "Port 5000 already in use"
Fix: Kill other app or change port in app.py
     Change: port=5000 → port=5001

Issue: "Connection refused"
Fix: Ensure Flask is running (check terminal)
     Wait 2-3 seconds
     Try: http://127.0.0.1:5000

Full troubleshooting: See README.md or INSTALLATION_GUIDE.py
